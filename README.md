# 태양계의 시간 · Solar Chronicle

태양계의 탄생부터 먼 미래까지, 시간을 움직이며 행성과 주요 사건을 살펴보는 웹앱입니다. 설치나 회원가입 없이 사용할 수 있습니다.

## 사용 방법

- 아래 시간 막대를 움직이거나 우주 화면을 좌우로 끌어 시대를 바꿉니다.
- **자동 탐험**을 누르면 선택한 시점부터 시간이 계속 흐릅니다. 사건이 몰린 구간은 천천히, 사건 사이가 먼 구간은 빠르게 지나갑니다. 다시 누르면 멈춥니다.
- 설명은 다음 사건에 도착할 때까지 남고, 카드 위에 다음 사건이 표시됩니다. 더 자세히 읽으려면 일시 정지를 누르세요.
- **처음부터**를 누르면 46억 년 전부터 바로 자동 탐험을 시작합니다. 마지막 사건에서는 멈추며, **다시 탐험**을 누르면 처음부터 재생합니다.
- **연대기 · 도감**에서 원하는 사건이나 천체를 선택합니다. 재생 중 선택하면 그 시점부터 계속 재생하고, 정지 중 선택하면 정지 상태를 유지합니다.
- **천체별 도감 → 지구**에서 바다·생명·대멸종·인류와 지구의 먼 미래를 찾아볼 수 있습니다.
- **더 알아보기**에서 감마선 폭발 가설, 달의 발자국, 은하 합병, 홀로세·인류세 등을 읽을 수 있습니다. 관련 사건 카드에도 연결 버튼이 있습니다. 설명을 펼치거나 이야기를 열어도 재생 중인 시간은 계속 흐릅니다. 이야기 창에서도 **일시 정지**와 **자동 탐험 이어가기**를 선택할 수 있습니다.
- **사건 따라보기**를 켜면 해당 천체를 확대합니다. **현재로**를 누르면 현재 시대로 돌아옵니다.
- 키보드의 좌우 화살표로 시간을 이동하고, 스페이스 키로 재생하거나 멈출 수 있습니다.

천체의 크기·거리·움직임은 이해를 돕기 위한 표현이며 실제 비율과 다릅니다. 과학 자료의 출처 링크와 논문 저자 표기는 유지했습니다.

전체 탐험은 태양계 탄생부터 백색왜성까지 44개 사건으로 구성되며 1×에서 약 8분 40초입니다. 첫 거성 단계 뒤 수축, 두 번째 거성 단계와 열적 맥동도 표현합니다. 지구의 미래 대륙 모양과 바다의 소실 과정, 태양의 크기 변화는 모형의 개념 표현입니다. 정확한 날짜를 알 수 없는 이야기는 자동 탐험에 임의의 날짜로 끼워 넣지 않았습니다.

과학 내용은 2026년 9월에 NASA·ESA·박물관·대학·논문 자료와 대조했습니다. 사건마다 **시점과 해석의 범위**와 **근거 읽기**를 통해 관측·해석·가설·미래 모형을 구분할 수 있습니다. 은하 합병은 2025년 연구와 2026년 사전 공개 재분석의 차이도 함께 소개합니다.

## 내 컴퓨터에서 미리 보기

이 폴더의 **index.html을 더블클릭**하면 웹 브라우저에서 열립니다. 별도 프로그램 설치나 명령어 입력은 필요하지 않습니다.

## 파일 구성

- `index.html`: 웹앱의 첫 화면
- `style.css`: 색상, 글꼴, 화면 배치
- `app.js`: 애니메이션과 버튼 동작
- `playback.js`: 멈춤 없이 사건을 따라가는 자동 탐험 속도 계산
- `events.js`: 태양계 사건 설명과 자료 출처
- `stories.js`: 날짜를 확정하지 않은 보충 이야기와 근거
- `evolution.js`: 지구 환경과 태양 진화의 개념 표현
- `favicon.svg`: 브라우저 탭 아이콘
- `.nojekyll`: GitHub Pages가 파일을 그대로 제공하게 하는 빈 파일
- `.gitignore`: 임시 파일과 개인 설정 등이 Git에 포함되지 않도록 지정한 목록

## GitHub Pages에 올리기

1. GitHub 저장소의 맨 위에 이 폴더 안의 파일을 올립니다. `index.html`이 다른 폴더 안에 들어가지 않도록 합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 파일을 올린 브랜치(보통 `main`)와 **/(root)**를 선택하고 **Save**를 누릅니다.
4. 게시가 끝나면 같은 화면에 표시되는 사이트 주소로 접속합니다.

HTML·CSS·JavaScript만 사용하는 정적 웹앱입니다. 서버, 데이터베이스, API 키나 빌드 과정은 필요하지 않습니다. 앱 내부 파일은 모두 상대 경로로 연결되어 저장소 이름이 붙은 주소에서도 사용할 수 있습니다.

서버로 사용자 데이터를 보내거나 저장하는 기능은 없습니다. 현재 탐험 위치와 설정은 새로고침하면 초기화됩니다. Google Fonts와 외부 자료 출처를 열려면 인터넷 연결이 필요하며, 인터넷이 없으면 기본 글꼴로 표시됩니다.

## 개발용 확인

Node.js가 설치된 경우 `node --test tests/*.test.cjs`로 재생 흐름, 자료 연결, 태양·지구 표현을 검사할 수 있습니다. 웹앱 사용에는 필요하지 않습니다.
